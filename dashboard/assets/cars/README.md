# Real team car photos (optional)

By default, the Teams page shows a generic, original car silhouette
tinted in each team's color — not a real photo. This is deliberate:
FastF1 doesn't provide car images (unlike driver headshots, which come
straight from the official data feed), and real F1 car photography is
licensed motorsport photography covered in trademarked sponsor logos
and team livery, which shouldn't be hardcoded into this project without
you personally holding the rights to use it.

If you have images you're licensed to use (your own photos, or stock
photography licensed for this purpose), drop them here with these exact
filenames and the dashboard will automatically use them instead of the
silhouette:

| Team | Filename |
|---|---|
| Red Bull Racing | `red_bull.png` |
| Ferrari | `ferrari.png` |
| Mercedes | `mercedes.png` |
| McLaren | `mclaren.png` |
| Aston Martin | `aston_martin.png` |
| Alpine | `alpine.png` |
| Williams | `williams.png` |
| Kick Sauber | `kick_sauber.png` |
| RB | `rb.png` |
| Haas F1 Team | `haas.png` |

`.jpg`, `.jpeg`, and `.webp` also work. No code changes needed — just
add the file and reload the app.
